# CLAUDE.md

Guidance for Claude Code sessions in this repository, local or cloud.

## What this is

A research repository on the Hodge conjecture: the precise statement and its variants (several are false),
known cases through 2026, the obstructions every strategy meets, and exact, test-covered computations that
verify the conjecture for Fermat varieties through Shioda's inductive structure. The conjecture is open, and
this repository does not prove it.

## Ground rules

- Do not claim or imply that the conjecture is proved. Label every new claim as **Theorem** (complete proof
  here), **Machine-checked**, **Cited** (only after reading the source), **Numerical**, or **Conjecture/Heuristic**.
- A computation verifies the conjecture for a variety only together with the theorem that turns it into a
  proof, as `hodge.fermat` does with Shioda–Katsura and Lefschetz (1,1). Name that theorem every time.
- A pattern in computations is evidence, not proof. Try to construct a counterexample before building on it.
- Run the checks before and after every change. A new failure is a regression until shown otherwise.
- Commit verified work in small steps and push before the session ends. Work left only inside a cloud
  session can be lost with it.

## Setup and checks

```bash
pip install pytest
python3 -m pytest -q tests      # 2026-11-14: 284 pass in about 25 s
```

The C helpers in `scripts/` give their build line in their header comment (`gcc -O2 ...`).
`scripts/fermat_span/ilp_short_hodge.c` also needs `-fopenmp`. Optional dependencies of the scripts (not of
`hodge/` or the tests): numpy (`scripts/galois_obstruction.py`), mpmath (`scripts/gamma_periods.py`),
python-flint and cypari2 (`scripts/fermat_formal_module.py`, `scripts/fermat_span/`).

## Where the next steps are

`docs/03-strategies-and-obstructions.md`, Section 3.5 "Concrete open problems where progress is realistic",
and `docs/04-fermat-computations.md` (where the classical method stops). For the open Fermat degrees, start from
`docs/fermat/03-galois-obstruction.md` §6: a cycle realizing ξ_44 must be defined over a field containing
√θ_44, the square root of an explicit product of sines and radicals. By Theorem L′ (via Anderson's description of
the maximal almost-abelian extension of Q), this square root lies in no field generated by roots of unity, radicals
of rational numbers, and the square roots attached to the other prime pairs. Open questions: whether Theorem G holds
for every degree 44k, and which geometric objects (complete intersections, CM abelian varieties and their torsion)
have this field as a field of definition. The sharpest target is in `docs/fermat/04-weil-route.md` §7: prove the
Weil classes of the 16-fold of Table 3 algebraic. That needs Markman's strategy for a non-quadratic CM field, where
his semi-regularity step is not yet available (dim X = 8 > 3).
