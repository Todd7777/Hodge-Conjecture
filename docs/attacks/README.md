# Proof attempts (work in progress)

Each file `NN-<strategy>.md` is one proof attempt from the adversarially refereed attack described in
`docs/03-strategies-and-obstructions.md` (strategies S1–S8 and the ladders of targets).

**Status (2026-11-07): drafts, not yet refereed.** The first run of the attack (2026-11-05) finished only two
attempts, `01-semiregularity.md` and `04-derived-K3.md`, before it hit a usage limit. Their three referees each
failed to run, so neither attempt has been checked by anyone yet. Treat every "Theorem" in these files as an
unchecked claim. A second run re-referees these two files, re-runs the remaining strategies, audits every claimed
result, and writes the outcome to `docs/06-attack-report.md`. Referee verdicts will be stored in
`_referee-verdicts.json` in this directory.

Neither draft claims a proof of the Hodge conjecture. Both report the top target as not proved and list their gaps.
