# Proof attempts (work in progress)

Each file `NN-<strategy>.md` is one proof attempt from the adversarially refereed attack described in
`docs/03-strategies-and-obstructions.md` (strategies S1–S8 and the ladders of targets).

**Status (2026-11-13): refereed.** All sixteen drafts `01`–`16` were refereed by independent referee runs, and every
correction they listed has been applied. Each draft has a one-line referee note under its status paragraph. The
summary of the verdicts is `docs/06-attack-report.md`. The full reports are in `referee-reports/`, and a
machine-readable list is in `_referee-verdicts.json`. Three drafts needed major revision (01, 04, 12); none proves
the Hodge conjecture or a new major case, and none claims to. Attack `17` (open Fermat degrees) was re-derived by
independent code and completed instead; see `docs/fermat/`.

No draft claims a proof of the Hodge conjecture. Each reports its top target as not proved and lists its gaps.
